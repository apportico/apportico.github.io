# Apportico app collection

Public one-page app showcase: https://apportico.github.io/apps/

Static HTML and CSS, no build step or JavaScript required. The repository’s existing GitHub Pages deployment serves this folder from `main`. The existing homepage and app support/privacy pages are unchanged.

## Assets and listings

- `assets/apportico-logo.png`: unmodified official Apportico GitHub organization avatar, retrieved from https://avatars.githubusercontent.com/u/142166324?v=4 on 8 November 2026.
- App icons and screenshots: official Apple App Store listing assets for Whenlet (6831935705), Dimensions Planner (6831661912), and Spin Sprout (6831902087).
- Live listing links checked on 8 November 2026. Availability and pricing vary by storefront.

To preview, serve the repository with a local static web server and visit `/apps/`. Before updating, check each App Store listing, validate asset paths, and test desktop and phone layouts. Do not add unreleased products or private release information.
