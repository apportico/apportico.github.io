Kebijakan Privasi Counterlift

Anda bisa bermain tanpa akun Counterlift. Aplikasi menyimpan progres dan preferensi di perangkat Anda. Aplikasi ini tidak menggunakan server game milik pengembang, iklan, analitik, atau pelacakan.

Game Center bersifat opsional. Saat Anda masuk melalui Counterlift, aplikasi mengirim progres pencapaian dan skor peringkat ke Apple. Counterlift menyimpan ID pemain khusus game di perangkat untuk memisahkan progres antar pemain Game Center. Pemain lain dapat melihat skor di peringkat global. Gunakan pengaturan berbagi aktivitas Game Center dari Apple untuk memilih siapa yang dapat melihat progres pencapaian Anda. Game Center

Apple memproses pembelian dan pemulihan. StoreKit memberitahu Counterlift apakah Full Game telah diaktifkan. Kami tidak menerima detail pembayaran Anda.
