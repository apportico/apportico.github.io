Cookie- og privatlivspolitik

Du kan spille uden en Counterlift-konto. Appen gemmer dine fremskridt og indstillinger på din enhed. Appen har ingen spilleserver hos udvikleren, reklamer, analyse eller sporing.

Game Center er valgfrit. Når du logger ind via Counterlift, sender appen dine fremskridt mod præstationer og dine ranglisteresultater til Apple. Counterlift gemmer et spillerspecifikt id for dette spil på din enhed for at holde Game Center-spillernes fremskridt adskilt. Andre Game Center-spillere kan se resultater på globale ranglister. Brug Apples indstillinger for aktivitetsdeling i Game Center til at vælge, hvem der kan se dine fremskridt mod præstationer. Game Center

Apple behandler køb og gendannelse. StoreKit fortæller Counterlift, om det fulde spil er låst op, men vi modtager ikke dine betalingsoplysninger.
