Sokongan Isyarat Malam

Cara bermain

Ketik suis untuk menukar laluan. Setiap kereta api perlu sampai ke stesennya sendiri. Apabila lebih daripada satu kereta api menggunakan lintasan, gunakan jadual untuk menghantarnya melalui rentak yang berbeza. Ketik Berlepas untuk menjalankan rancangan anda. Jika gagal, Adjust Plan mengembalikan kereta api ke permulaan dan mengekalkan pilihan suis dan masa anda.

Pulihkan Permainan Penuh

Ketik kaunter tahap dan tatal ke Pulihkan Pembelian. Gunakan Akaun Apple yang sama yang membeli Full Game. Pembelian itu menambah 100 teka-teki kepada 12 teka-teki percuma.

Kenalan
