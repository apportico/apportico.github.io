Sokongan Isyarat Malam

Cara bermain

Ketik suis kereta api untuk menukar laluan. Bimbing setiap kereta api ke stesennya sendiri. Apabila dua kereta api berkongsi lintasan kereta api, berikan mereka masa lintasan yang berbeza. Jadual waktu menunjukkan bila setiap kereta api akan sampai ke setiap lintasan. Ketik Berlepas untuk menjalankan rancangan. Laraskan Rancangan mengembalikan kereta api ke permulaan dan mengekalkan tetapan laluan dan berlepas anda.

Pulihkan Permainan Penuh

Ketik kaunter tahap dan tatal ke Pulihkan Pembelian. Gunakan Akaun Apple yang sama yang membeli Full Game. Pembelian itu menambah 100 teka-teki kepada 12 teka-teki percuma.
