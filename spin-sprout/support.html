Support · Spin Sprout

Create a wheel, type or paste one choice per line, then save. One-off spins allow repeats. Group rounds remove each pick until everyone has had a turn. Undo restores the last pick. Editing clears round progress after confirmation. Reset starts the round again. Weights from 1 to 100 set relative chances. Settings contains backup export and import. Import keeps existing wheels and adds copies. If a saved file cannot be read, it is preserved and saving pauses; export the original before recovery.
