Confidentialité · Spin Sprout

Vos roues sont enregistrées sur cet appareil. Nous ne collectons pas les données de l’app et n’exploitons aucun serveur. Aucun compte, publicité, analyse ou IA en cours d’utilisation. Les préférences d’apparence sont locales. Les sauvegardes de l’appareil peuvent inclure les données de l’app. L’export et le partage envoient uniquement le contenu choisi vers la destination sélectionnée, qui applique ses propres pratiques de confidentialité. Supprimez une roue pour la retirer de l’app. Gérez séparément les fichiers exportés et les sauvegardes de l’appareil.

Ce site est hébergé sur GitHub Pages. GitHub peut traiter des données techniques de requête, dont votre adresse IP, pour fournir et sécuriser le site. Cela est distinct de l’app. Si vous contactez l’assistance par courriel, nous recevons le message et les informations que vous choisissez d’inclure. N’envoyez pas de mots de passe ni le contenu privé de vos sauvegardes. Nous utilisons cette correspondance pour répondre à votre demande. Pour toute question de confidentialité, utilisez l’adresse ci-dessous.
