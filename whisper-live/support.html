Support · Whisper Live

Set up the keyboard

  1. Open Settings › Apps › Whisper Live › Keyboards (the app's welcome tour has a button that takes you there).
  2. Turn on Whisper Live and Allow Full Access.
  3. In any app, hold the globe key and choose Whisper Live, then tap the mic.

Full Access is only used so the keyboard can receive text from the Whisper Live app on the same device. Keyboards can't use the microphone themselves, so the app records and the keyboard types the result.

Common questions

  • Nothing is typed: make sure Allow Full Access is on, and open the app once so it can listen. You can also copy the last text from the app.
  • A language isn't recognised: the first time you use a language, iOS may download its speech model once. After that it works offline.
  • Apple Watch: install Whisper Live from the Watch app on your iPhone. The iPhone needs to be nearby to turn recordings into text.
  • Words come out wrong: add names and terms in Settings › Vocabulary, or set up a replacement.
